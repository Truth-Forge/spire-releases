Spire

An Apple-native macOS application for running Linux containers through Apple's container runtime — with on-device MLX inference serving built in.

Download Spire 1.4.0

Notarized by Apple · macOS 26 or later · Apple silicon

Installation

Unzip and drag Spire.app to your Applications folder. The app is signed with a Developer ID certificate and notarized by Apple — it opens without warnings on a standard Mac. Updates are delivered automatically inside the app.

What it does

  • Plans and applies Apple container deployments from reviewable, typed manifests
  • Serves local MLX models (chat, embeddings, rerank) over an OpenAI-compatible endpoint
  • Exposes an MCP server so AI agents can drive deployments with operator-granted capabilities
